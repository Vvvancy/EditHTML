# apps/web

Web 编辑器：打开任意 .html（保真模式）、.md、.ehtml；笔记文件夹、文件树、搜索、双链、批量导入。

参见 任务 T2.7 T5.1–T5.4

## 当前状态（T2.7 最小页面）

打开任意 `.html` → 保真模式就地改字 → 保存写回原文件。逻辑在 `@edithtml/runtime`（打开器）与
`@edithtml/importer`（保真会话），本应用只负责把两者接起来（`src/opener.ts`）和界面（`src/main.ts`）。

```sh
pnpm install
pnpm --filter ./apps/web dev      # 打开终端里显示的 http://localhost:5173/
pnpm build                        # 产物在 apps/web/dist/
```

写回原文件需要 File System Access API（Chrome / Edge，`localhost` 或 https）。其他浏览器只能「保存」为下载新文件。

### 行为

- **打开**：工具栏「打开」（Chrome/Edge 走 `showOpenFilePicker`，可写回；其他浏览器为普通文件选择框）、`Ctrl/⌘+O`，或把文件拖进窗口
  （Chrome/Edge 拖入也能拿到可写回的句柄）。只支持 UTF-8；BOM 会原样保留。
- **页面脚本**：含脚本（`<script>` 或 `on*` 属性）的文件第一次打开时脚本**不运行**，顶部提示「此文件包含脚本，是否运行？」：
  「运行」只运行这一次；「始终运行此文件的脚本」记住这段脚本的指纹（内容哈希，存在本浏览器的 localStorage），
  以后打开脚本相同的文件直接运行，脚本被改过会重新询问。运行脚本会用当前内容（含未保存的修改）重建页面。
- **编辑**：正文段落、标题、列表项、表格单元格可直接改字；脚本生成的内容（图表等）标灰、不可编辑。
- **编辑 HTML 源码**（T2.5）：鼠标停在一个顶层区域（段落、标题、列表、图表……）上，右上角出现「编辑 HTML 源码」按钮，
  点开是 CodeMirror 弹层，内容是该区域当前的源码（图表区域是容器连同生成它的 `<script>`，不含图表库画出来的 DOM）。
  改完「应用」（`Ctrl/⌘+Enter`）或「取消」（`Esc`）；勾选「实时预览」时停顿片刻就把改动替换进页面预览，取消则复原。
  保存时该区域写入的就是你在弹层里写的那段 HTML（缩进、注释原样）；脚本运行中替换图表源码，脚本会重新执行。
  CodeMirror 单独成包，第一次打开弹层时才加载。
- **保存**：「保存」或 `Ctrl/⌘+S`。只改动编辑过的字节；保存后页面不刷新（就地在新内容上重新挂载）。

### 手动验收（T2.7）

1. 准备一个现有的 HTML 笔记，例如 `~/notes/test.html`（建议先 `git init` 并提交一次，便于看 diff；最好带 UTF-8 BOM 或 CRLF 的文件也试一次）。
2. `pnpm --filter ./apps/web dev`，用 Chrome 打开 `http://localhost:5173/`。
3. 点「打开」选中该文件（或拖入窗口）。工具栏显示文件名；若文件含脚本，顶部出现黄色提示条。
4. 若有提示条，点「运行」：图表等动态内容出现并标灰；正文仍可编辑。
5. 在某个段落里改一个字：文件名旁出现「●」，标签页标题前有「●」。
6. 按 `Ctrl/⌘+S`（或点「保存」）。第一次写回时 Chrome 会询问是否允许编辑该文件，选「保存更改」。状态栏显示「已保存 时:分:秒」，「●」消失。
7. 在终端中 `git diff`：只有被改的那一行变化，其他字节（缩进、注释、属性顺序、BOM、换行符）不变。
8. 在浏览器新标签页直接打开该文件（`file:///…/test.html`）并刷新：能看到改动。
9. 回到编辑器再改一处并保存，确认第二次保存同样只改动那一处（会话已在新内容上重开）。
10. 可选：用 Firefox / Safari 重复 3–6，保存应变为下载 `test.html`。

### 手动验收（T2.5 区域源码编辑）

1. 打开 `tests/fixtures/html/03-echarts.html` 的一个副本（把 `<script src="./vendor/echarts.min.js">` 换成 CDN 地址
   `https://cdn.jsdelivr.net/npm/echarts@5.5.1/dist/echarts.min.js` 才能看到图表），点「运行」。
2. 鼠标移到第一段正文上：段落出现虚线框，右上角出现「编辑 HTML 源码」；移到 iframe 外按钮消失。
3. 点按钮：弹层显示 `<p>本周 PV…</p>`，有行号与 HTML 语法高亮。改一个字，勾选实时预览时页面随之变化；按 `Esc`：页面复原，「●」不出现。
4. 再打开，改成两段 `<p>`（自己加缩进或注释），`Ctrl/⌘+Enter` 应用：页面显示两段、出现「●」；新段落可以直接改字。
5. 移到第一个图表上：按钮出现，弹层里是 `<div id="pv-chart" class="chart"></div>` 加其后的 `<script>`（不含 canvas）。
   把数据 `[820, 932, …]` 改掉并应用：图表按新数据重绘。
6. 保存后 `git diff`：只有这两个区域变化，且内容与弹层中写的逐字节一致。`Ctrl/⌘+Z` 目前未接到宿主（见 T2.6 说明），撤销在 API 层已测试。

### 已知限制

- 页面在 blob URL 下渲染，原文件中的**相对路径资源**（本地图片、CSS、`<script src="./x.js">`）无法加载；绝对 URL / CDN 资源正常。
- 只支持 UTF-8（非 UTF-8 文件会提示，不会打开）。
- 运行脚本时页面与编辑器同源，受信任的脚本可以访问编辑器页面——只对自己信任的文件点「运行」。
- 激活脚本是按文档顺序逐个重建 `<script>`，并补发 `DOMContentLoaded` / `load`；依赖解析期细节的脚本（跨多次 `document.write` 拼接标签等）可能表现不同。
- 文件在编辑器外被修改（例如 agent 同时改了它）不会被检测到，保存会覆盖。
- 区域源码：替换进来的脚本在同一个页面全局环境中再次执行，顶层 `const`/`let`/`class` 与原脚本同名时会报重复声明
  （如 03-echarts 的热力图脚本），保存后「运行」重建页面即可看到效果；`var` / 函数式写法不受影响。
